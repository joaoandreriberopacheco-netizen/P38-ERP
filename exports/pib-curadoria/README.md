# PIB — Curadoria de fotos

Seleção equilibrada: **125 fotos em pastas → 50 essenciais + 75 de fora**.

| Ficheiro | Conteúdo |
|----------|----------|
| `pib-50-selecionadas.zip` | 50 fotos escolhidas (~4 por evento) |
| `pib-75-de-fora.zip` | 75 fotos que ficaram de fora |

Dentro de cada ZIP há subpastas por evento (Batismo, Cultos, Gincana, etc.).
