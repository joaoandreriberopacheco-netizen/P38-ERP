# Catálogo Arielle — Carmelo Fior (P38)

Site estático B2B da marca **Arielle** (grupo Carmelo Fior), no mesmo template do catálogo Formigres.

## Regenerar

```bash
npm run catalogo:publicar-arielle
```

## Preços

Derivados da tabela Formigres com **~3% de desconto** (um pouquinho mais barato), por formato e linha.

## Deploy Vercel

Projecto isolado `catalogo-arielle-p38`. Secret GitHub: `VERCEL_CATALOGO_ARIELLE_PROJECT_ID`.

Fonte oficial: [carmelofior.com.br](https://www.carmelofior.com.br/produtos?category=4)
