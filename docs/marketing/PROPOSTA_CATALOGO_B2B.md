# Proposta comercial — Catálogo B2B

Página para enviar a **prospects** (distribuidor, lojista, representante) antes ou durante a conversa comercial.

## Link

Após deploy na `main`:

**https://p-38erp.vercel.app/proposta-catalogo-b2b.html**

## O que a página faz

- Explica o problema (PDF/WhatsApp/planilha) vs. catálogo B2B com link único
- Lista funcionalidades: carrinho, PDF, desconto, Suframa, mobile
- Liga às demos: Formigres, Arielle, Tintão (caso real)
- Propõe **piloto 30 dias · 1 operação**
- CTA: e-mail e copiar link

## Roteiro rápido (WhatsApp)
