# Roteiro — conversa com parceiro (5 min)

Para software house regional, distribuidor ou investidor com tese vertical.

## Abertura (30 s)

> “Construí o P38 porque Omie e similares não servem o **chão do varejo** — só o escritório. É ERP mobile-first para quem opera e manda no mesmo negócio.”

## Demo ao vivo (3 min)

1. **Telemóvel** — abrir margem ou planejamento financeiro  
2. **Operação** — conferência ou sugestão de compra (stock abaixo da cota)  
3. **Landing** — `https://p-38erp.vercel.app/landing.html`

## Diferenciais (1 min)

- Processo varejo completo (não só NF)
- Dono remoto + equipa no chão — mesma base
- Stack portável: Next + Supabase (sem lock-in no-code)
- Código + docs — pronto para verticalizar ou white-label **regional**

## Perguntas que o parceiro fará

| Pergunta | Resposta honesta |
|----------|------------------|
| Quantos clientes? | 1 hoje — operação real; piloto externo a abrir |
| É SaaS? | Pode ser; hoje é IP validado + roadmap multi-tenant |
| Quanto custa replicar? | Meses de engenharia — fluxos já existem |
| Integra fiscal? | Foco operacional; fiscal via processo/contador parceiro |
